## 🔥 Featured project

### Hearth — Chat. Connect. Create.

A soft, pastel chat app for real-time conversations.

- Real-time messaging with Google sign-in
- Presence, typing indicators, and read receipts
- Swipe-to-reply, emoji reactions, and reply threads
- GIF search, photo messages, and a PWA share target
- Installable PWA with web push notifications
- Consistent cross-platform emoji rendering

Built with **Next.js (App Router)**, **React**, **TypeScript**, **Tailwind CSS**, and **Firebase** (Auth + Firestore), deployed on **Vercel**.

[Repository](https://github.com/Sampreeth004/hearth) · [Live app](https://hearth-messenger.vercel.app)
